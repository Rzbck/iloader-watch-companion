# Support

This repository coordinates the Apple Watch companion sideloading work. Please report problems in the repository that owns the failing layer whenever possible.

## Use this repository for

- Apple Watch companion integration questions spanning iLoader + isideload;
- reproducible compatibility reports;
- documentation corrections;
- regression reports against the known-good Watch companion path;
- coordination of the upstream contribution effort.

## Use upstream/fork repositories for source-specific bugs

- iLoader upstream: https://github.com/nab138/iloader/issues
- isideload upstream: https://github.com/nab138/isideload/issues
- working iLoader fork: https://github.com/Rzbck/iloader
- working isideload fork: https://github.com/Rzbck/isideload

Before publishing logs, remove Apple account information, device identifiers, signing/provisioning data, pairing material, and personal application data. For security-sensitive reports, follow `SECURITY.md` instead of opening a normal issue.
